# derick-apps – The What If Lab autopost

Private automation that publishes The What If Lab's own videos from Google Drive to YouTube, Facebook, Instagram and Dailymotion on a fixed schedule (reels 07:00 and 18:00 IST; main videos 14:00/18:00 IST on YouTube and Dailymotion).
